# 领域 Profile：实验自动化与仪器控制

## 必须逐项确认的六件事（未确认前全部记 `UNKNOWN`，不得臆造阈值）

| 项 | 内容 | 状态 |
|---|---|---|
| 前置条件 | 设备连接、工作模式、量程、配置 | UNKNOWN |
| 执行条件 | 哪些命令允许自动发送、哪些需授权 | UNKNOWN |
| 完成条件 | 如何判断设备**真的**完成了测量，而非仅接受了命令 | UNKNOWN |
| 失败处理 | 超时、通信中断、返回值异常、数据不完整 | UNKNOWN |
| 恢复条件 | 哪些状态允许自动恢复、哪些必须人工检查 | UNKNOWN |
| 数据保护 | 原始数据如何保存、防覆盖/重复采集/错误归档 | UNKNOWN |

## 三类验收不可互相替代

| 类别 | 核心问题 |
|---|---|
| 程序正确性 | 代码是否按规格执行，错误处理是否有效 |
| 设备执行正确性 | 仪器是否真的执行了要求的操作并处于预期状态 |
| 实验数据有效性 | 数据是否完整、单位/校准/测量条件是否满足要求 |

## 硬规则

- 未接入真实设备的结论只能标 `NOT_RUN`，**不得**报"硬件测试通过"。
- 安全相关参数（量程、功率、温度上限、激光）不得由 Agent 自行决定。
- 任何"自动重试"必须依据设备手册与实测状态，不能凭空设定次数与间隔。
